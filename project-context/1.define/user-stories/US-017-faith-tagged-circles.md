### 2. Narrative

As a participant, I want to find circles that are explicitly faith-centred, or ignore that dimension entirely, so that faith-centred fellowship is available without being required.

### 3. Acceptance Criteria

1. A circle can carry an optional faith-context tag set by its facilitator or the admin.
2. Circles can be filtered by the tag; people cannot be filtered by faith.
3. No feature can be reached only by declaring a faith (MD-010).
4. Joining a faith-tagged circle does not write any faith data to my profile (MN-004).

### 4. Scope Notes

- **In Scope for MVP**: Circle tag and filter.
- **Deferred**: Denomination or tradition taxonomies.
